# Wiki

Other useful information about the project can be found in the [wiki](https://codeberg.org/comaps/comaps/wiki/).

Warning: information can be outdated or imprecise, but can be good to give pointers on some subjects.

## Contributing

Contributions can be done via the web interface of Codeberg directly, or via git (it behaves like a regular git repository):

```shell
git clone https://codeberg.org/comaps/comaps.wiki.git
git clone ssh://git@codeberg.org/comaps/comaps.wiki.git
```
